# Tabs and windows

Each tab shows one folder, with its own Back/Forward history and selection. Tabs are ordinary
macOS window tabs, so everything the tab bar does elsewhere on your Mac works here too.

## Opening tabs

| To | Do this |
|---|---|
| Open a new tab on the same folder | **Cmd+T** |
| Open a folder in a new tab | **middle-click** it, or select it and press **Ctrl+Return**, or right-click → **Open in New Tab** |
| Open a sidebar place in a new tab | right-click it → **Open in New Tab** |
| Open a new window on the same folder | **Cmd+N** |

Folders opened with middle-click or Ctrl+Return open **in the background**, like links in a
browser, so you can open several and keep going.

The tab bar appears as soon as there are two tabs. To always show it, choose
**View → Show Tab Bar**.

## Switching and closing

- **Ctrl+Tab** and **Ctrl+Shift+Tab** go to the next and previous tab.
- **Cmd+1** to **Cmd+8** go to that tab, **Cmd+9** to the last one.
- **Cmd+W** closes the tab (or the window, if it's the last tab).
- **Shift+Cmd+T** reopens the most recently closed tab, in the folder it was showing. It
  remembers the last 20.

## Moving tabs around

- Drag a tab along the tab bar to reorder it.
- Drag a tab **out of the bar** to make it its own window, or onto another window's tab bar to
  move it there.
- **Window → Merge All Windows** puts every window's tabs into one window.
- **Window → Show All Tabs** (Shift+Cmd+\\) shows every tab as a thumbnail.

Dragging files **onto a tab** isn't supported; drop them on a sidebar place instead, or switch
to the tab first (hovering a file over a folder in the list opens it).

## Reopening where you left off

When you quit and open File Manager again, your windows and tabs come back, each in the folder
it was showing, with the same tab selected. Folders that no longer exist are skipped. Back and
Forward history and the selection aren't kept.

Turn this off in [Settings](Settings.md) → **Reopen windows and tabs from last time**; then
File Manager starts with one window on your home folder.

If macOS asks whether to reopen windows after a restart, that's separate: File Manager
reopens its own tabs either way.
