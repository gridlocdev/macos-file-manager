# File Manager documentation

File Manager is a file browser for macOS that works the way Windows Explorer and Linux file
managers (Nautilus, Dolphin) do: Backspace goes up a folder, F5 refreshes, you can type a path
straight into the address bar, and Cmd+H shows hidden files. It uses Cmd where Windows and Linux
use Ctrl, and keeps the Mac habits that are worth keeping, such as Return to rename.

These pages explain **how to use the app** and **where it differs from what you're used to**.
